A letter and quill is an item that can be used to write and edit text. It only has 1 page, but it can fit roughly one 1/3 of a page more text than a single book page.\
Folding finalizes it and prevents further edits, creating a [letter](@envelope:letter).

### Copying
Letter and Quill can be used to copy a [letter](@envelope:letter), but crafting both items together.

### Folding
Letters can be folded by pressing the "Fold" button while in the interface, converting it to a [letter](@envelope:letter) item.\
After it has been folded, it cannot be edited again.
