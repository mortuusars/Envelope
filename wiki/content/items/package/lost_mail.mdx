**Lost Mail** is a [package](@envelope:package) with a loot table and custom name, that can be bought from <Asset location="envelope:gui/address_mail_service" width={20} /> **Mail Service** or found in loot.

## Obtaining

### Mailing
Lost mail package can be bought from <Asset location="envelope:gui/address_mail_service" width={20} /> **Mail Service** by sending 1 [diamond](@minecraft:diamond).

### Loot
Lost mail package has a chance to spawn on [collapsed mail hub's](@envelope:collapsed_mail_hub) storage platform, in one of the barrels.

### Natural Generation
Lost mail package in a block form generates on several [collapsed mail hub](@envelope:collapsed_mail_hub) platforms.

## Contents
Lost mail can contain several types of loot:
- Junk
- Plants
- Blocks
- Metals
- Tools
- Weapons
- Valuables

Each type is a separate loot table that contains specific items.

Lost mail can contain pretty valuable items like [lapis](@minecraft:lapis_lazuli), [gold](@minecraft:gold),
[amethyst shards](@minecraft:amethyst_shard), [bottles of enchanting](@minecraft:experience_bottle),
[diamonds](@minecraft:diamond), diamond tools, [mace](@minecraft:mace), [trident](@minecraft:trident),
[netherite scrap](@minecraft:netherite_scrap).
